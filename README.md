# Anti gold farm

This is a simple paper plugin that prevents use of gold farms. Useful for economies using gold ingots.

## Permissions

| Permnode              | default | description                                         |
|-----------------------|---------|-----------------------------------------------------|
| `antigoldfarm.reload` | op      | Allows the player to reload the configuration file. |
